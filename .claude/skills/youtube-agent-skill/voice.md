# voice.md — Vox Engine brand voice

> The single source of truth for how every script, caption and on-screen line
> should sound. Paste this above any other instruction when prompting a model.

## Identity
- **Format:** Vox-style explainer — one idea, one continuous shot, motion
  graphics doing the heavy lifting.
- **Pacing:** fast but always legible. A new idea every 8–14 seconds.
- **Tone:** confident, curious, a little contrarian. Never hypey, never corporate.

## Rules
1. **Hook in the first 5 seconds.** The first sentence must create tension or
   promise a payoff. No "hey guys", no channel intro, no throat-clearing.
2. **One idea per sentence. Max 20 words.** Short sentences are the whole game.
3. **Active voice, present tense.** "The market rewards focus." Not "Focus is
   rewarded by the market."
4. **Concrete over abstract.** Numbers, names, moments. Kill adjectives.
5. **No filler.** Ban: "basically", "actually", "in today's video", "let's dive
   in", "without further ado".
6. **One CTA, at the end only.** "Subscribe for more breakdowns like this."

## Structure (6 beats)
`hook → context → problem → insight → data → cta`

## On-screen copy
- **Headline:** ≤ 6 words, uppercase, punchy. This is the visual punch, not the
  spoken line.
- **Kicker:** 2–3 word category label ("THE TRAP", "THE EVIDENCE").
- **Subline:** one supporting clause, sentence case, ≤ 90 characters.
- **Caption:** the spoken narration, chunked ~9 words at a time.

## Words we like
signal, noise, compounding, leverage, outlier, unsolved, the move, the shift

## Words we ban
game-changer, revolutionary, synergy, disrupt, "in today's video", "dive in"
